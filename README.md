# AI Workflow Platform

A backend API for managing AI-powered workflow tasks.

This project is being built using FastAPI as part of a larger AI workflow automation system.

---

## Features

- Create tasks
- View all tasks
- View single task
- Delete tasks
- Input validation using Pydantic
- Interactive API testing with Swagger UI

---

## Tech Stack

- Python
- FastAPI
- Pydantic
- Uvicorn
